🔬 Metodología y Fuentes
🏛️
Datos Oficiales CABB
API GesDeportiva / AFMB. Actas de partido verificadas endpoint por endpoint. No estimaciones de fuentes externas.
📐
Métricas FIBA
eFG%, TS%, Valoración FIBA, Ratio Rec/Pérd. Percentiles calculados vs plantel de 14 jugadoras con ≥8 PJ.
🗺️
Zonas de Tiro
Categorización por zona: pintura, media distancia, triple. Volumen e intento por zona extraído de actas AFMB.
📱
Plan de Mejora
4 objetivos medibles por jugadora, derivados de sus métricas débiles reales. Progreso persistido en localStorage.
🚀 Cómo compartir por teléfono
⚡
Netlify Drop
La opción más rápida. En 30 segundos tenés una URL pública que funciona en cualquier celular. Gratis para siempre en el plan free.
1 Entrá a app.netlify.com/drop
2 Arrastrá la carpeta CAB/ completa a la pantalla
3 Netlify genera: xyz.netlify.app/
4 Mandás el link por WhatsApp → el padre abre en su celular 📱
✓ HTTPS automático · ✓ Sin cuenta requerida · ✓ CDN global
🐙
GitHub Pages
Para tener el producto versionado con URL permanente. Ideal si vas a seguir actualizando los dossiers. También 100% gratis.
1 Crear repo en github.com/new (puede ser privado)
2 Subir los archivos HTML desde la carpeta CAB/
3 Settings → Pages → Source: Deploy from branch / main / root
4 URL: tuusuario.github.io/repo/intake_dossier.html
✓ URL permanente · ✓ Versionado con git · ✓ Fácil actualizar
🔗
Exportar como Link
Ya implementado en el Plan de Mejora. Tab Progreso → botón "Generar link para compartir". El progreso viaja en la URL — funciona sin servidor.
¿Cómo funciona?
1. Jugadora completa el intake en su PC
2. En el plan de mejora toca "🔗 Generar link"
3. El estado (checks + historial + % actuales) se codifica en la URL
4. Manda el link por WhatsApp → el padre lo abre en su celular
5. Se restaura automáticamente con toast verde ✓
✓ Sin servidor · ✓ Sin cuenta · ✓ Funciona offline si ya se cargó
